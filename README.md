# Скрудж — личный финансовый Telegram-бот на Claude Code

Скрудж ведёт учёт твоих личных денег прямо в Telegram: понимает текст, фото чеков и скриншоты банковских приложений, разносит траты и доходы по статьям, считает лимиты, копит на цели и присылает сводку с графиком.

«Мозг» бота — не отдельная нейросеть, а твой собственный Claude Code: бот просто передаёт ему каждое сообщение и просит сохранить результат в локальную базу. Поэтому для работы бота обязательно нужен установленный и авторизованный **Claude Code** (как его поставить — отдельная тема, здесь не описываем).

## Что нужно, прежде чем начинать

- Установленный и авторизованный Claude Code (команда `claude` работает в терминале)
- Node.js 20 или новее
- Аккаунт Telegram

## Шаг 1. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**, напиши ему `/newbot`.
2. Придумай имя бота (как он будет отображаться) и юзернейм (обязательно заканчивается на `bot`, например `moi_skrudzh_bot`).
3. BotFather пришлёт токен — длинную строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Он понадобится на шаге 3, никому его не показывай.

## Шаг 2. Скачать репозиторий и поставить зависимости

```bash
git clone https://github.com/skryabinairina82-maker/skrudzh-money-bot.git
cd skrudzh-money-bot/bot
npm install
```

## Шаг 3. Вписать токен

В папке `you/` лежит файл `env-example.txt`. Скопируй его в `.env` и впиши свои данные:

```bash
cd ../you
cp env-example.txt .env
```

Открой `.env` в любом редакторе и заполни:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
OWNER_NAME=Твоё имя
```

Голосовые сообщения — по желанию: заведи бесплатный ключ на [deepgram.com](https://deepgram.com) и добавь `DEEPGRAM_API_KEY=` в тот же `.env`. Без него бот просто попросит присылать траты текстом вместо голосовых.

## Шаг 4. Запустить

Из папки `bot/`:

```bash
AGENT_HOME="$(pwd)/../you" node index.js
```

В терминале появится `[skrudzh] started for <твоё имя>` — бот подключился к Telegram и ждёт сообщений.

## Шаг 5. Познакомиться с ботом

Открой своего бота в Telegram (по юзернейму, который задал в BotFather) и нажми **Start**. Бот поздоровается и расскажет, что умеет. Дальше просто пиши или присылай фото/голосовые — он сам разберётся, куда записать.

Первое сообщение может обрабатываться дольше обычного — Claude Code запускается с нуля.

## Если хотите вдвоём — свой бот каждому

Заведите у BotFather второго бота, скопируйте папку `you/` (например, в `partner/`) со своим `.env`, и запускайте вторым терминалом:

```bash
AGENT_HOME="$(pwd)/../partner" node index.js
```

Это два полностью независимых бота с отдельными базами — никакие данные не пересекаются.

## Чтобы бот работал постоянно, а не только пока открыт терминал

Для пробы достаточно шага 4. Для повседневного использования бот должен работать 24/7 — самый простой вариант: запустить на любом VPS-сервере через `systemd` или менеджер процессов вроде `pm2`. Это уже отдельная тема сама по себе.

## Как это устроено

- `bot/` — общий код: логика Telegram-бота (`index.js`), характер и правила Скруджа (`persona.md`), скрипты для работы с базой (`scripts/`), сама база данных SQLite создаётся автоматически в `data/` внутри папки экземпляра (`you/`, `partner/` и т.п.).
- Записи в базу выполняются не напрямую, а через отдельные CLI-скрипты (`scripts/record.js` и другие) — так у Claude нет прямого доступа к SQL, только к готовым, безопасным операциям.
- Никакого отдельного сервера или API нет: Telegram-сообщение → запрос к Claude Code → Claude вызывает нужный скрипт → ответ пользователю.
